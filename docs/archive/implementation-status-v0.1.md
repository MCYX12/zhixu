## 当前使用方式

本次已启动模型和 Gateway，可打开 http://127.0.0.1:9000 ，使用项目内 `data/owner.key` 中的密钥。服务仅本机可用，尚未设为开机自启。

本机重启模型时可执行：

```sh
python3 scripts/start_model.py --binary /Users/mac/gemma-lyrics/llama.cpp/build/bin/llama-server
```

另一个终端运行 `uv run python -m local_ai serve`。账号和示例索引已初始化，无需重复创建。

当前交付是可运行的本地基础版本，不是总计划全部完成。后续优先次序：NAS 接入与标注集 → 语义混合检索 → WebUI/运维 → 按用户选择开启外部能力。NAS 接入等待用户挂载路径，其他阶段尚未实施。
