# 实施状态 · v0.3 企业试点

日期：2026-09-14。执行依据：[v2.2 总计划书](../mac_m4_local_first_ai_v1.md)。用户要求企业落地导向、美观前端、暂不使用 NAS，默认本地，本轮已授权手动联网搜索。

## 已实现

- 「知序」自有工作台：深绿侧栏、浅色内容区、AI 工作台/文档知识库/历史会话/系统状态四页，适配桌面与手机。
- 本地 Markdown 渲染和清洗，前端依赖固定且随项目提供，无 CDN。流式问答、停止、复制、来源预览、会话导出、保存失败重试。
- 网页密钥登录换取 8 小时 HttpOnly 会话，CSRF/同源写入检查、HTTPS 下 Secure Cookie、停用账号即时失效。
- 成员/管理员角色、私有/组/全体已认证用户可见文档。管理员不绕过其他成员的私有读取权限。成员与组通过本机 CLI 管理。
- 本机 PDF、DOCX、Markdown、文本代码上传，独立解析进程、文件/正文/数量/原件总量限制。PDF 页码、DOCX 普通表格文字、预览、原件下载、共享修改与删除。失败解析不发布空文档，重名上传不覆盖。
- 原件、片段、ACL、账号会话、聊天历史和操作事件均存于本机 SQLite。聊天历史按账号隔离、版本冲突检测，恢复时再次过滤来源权限。
- 保留 v0.1 的本地 Qwen3.5-9B、Metal 推理、SSE、BM25 检索、ACL、有限队列、超时取消、目录文本入库和备份能力。
- M6：本机 SearXNG、显式公开搜索词、owner 白名单、网页读取与清洗、DNS 固定连接与重定向检查、来源日期/正文/摘要区分、联网引用预览与历史保存、搜索取消及故障提示。
- 搜索依赖独立锁定，本机 8888 端口，当前只启用已验证的 Bing；AUTO/LOCAL/KNOWLEDGE 不自动联网，云端保持关闭。
- 项目新增 AGENTS.md，固定每轮开始/结束核对总计划以及完工汇报已实现与未实现项的协作要求。
- 数据库采用增量迁移；修改前保留 `data/before-enterprise.sqlite3` 本机备份；M6 修改前另存 `data/before-web.sqlite3`，原账号和用户会话保留。

- 原有真实 HTTP socket 测试覆盖排队取消及流式断连，上游使用可控后端；自动测试不用于宣称模型答案质量。
- Ruff 检查、格式检查、Node 语法检查、Prettier 检查通过。两条测试依赖上游弃用提示尚存，不影响当前通过。
- 真实浏览器完成：owner 登录 → 上传本机 `examples/workspace-guide.md` → 预览 → 知识库提问 → 本地模型流式回答 → 来源展示 → 保存成功 → 刷新与恢复历史。
- 实际提问「根据工作空间使用指南，演示标识是什么？请简短回答并引用来源。」模型返回「演示标识为 ZX-PILOT-20260913。[1]」。来源可打开；该测试仅证明示例闭环，不等于企业语料质量验收。
- 浏览器检查桌面 1280×720 和手机 390×844；手机会话无横向溢出，导航可进入系统状态。状态页正确显示模型就绪、active=0、waiting=0。
- 登录 Cookie 和已有文档/会话跨页面刷新保留。当前示例指南为 owner 私有资料，原有 PWM 示例保留。

## M6 真实运行验收

- 浏览器完成 owner 登录 → 手动选择联网搜索 → 填写公开搜索词 → 本地 Qwen 流式回答 → 展示 3 个来源 → 保存历史 → 刷新后恢复。
- 来源预览展示正文节选/仅搜索摘要、原站链接、检索时间；无发布日期时显示“未提供”，不伪造时间。
- 手机 390×844 下公开查询面板可用，文档宽度 390，无横向溢出；已恢复桌面视口。
- 重启搜索与 Gateway 后，服务均就绪，原账号/知识库/会话保留。搜索已启用 owner，其他模式仍本地。
- 真搜索+本地模型另一次短样本返回官方文档中的 264 个搜索服务并引用 [2]；全程约 11.54 秒，结束 active=0/waiting=0。原始公开测试记录见 [m6-runtime-validation.json](m6-runtime-validation.json)。这不是持续负载指标，也不承诺该数量永远不变。
- 正文读取失败的来源明确降级为摘要。当前 Bing 可用；其他引擎曾出现连接失败/超时，已从当前配置移除。

## 模型与既有运行记录

Mac mini M4，32GB 统一内存。模型 Qwen3.5-9B Q4_K_M 已通过锁定 SHA256 校验；复用本机 llama.cpp b9716 / db52540f7。模型仅监听 `127.0.0.1:8080`；两个槽位，每槽 8192 tokens，提示缓存上限 1024 MiB，每槽最多 8 个上下文检查点。

v0.1 短样本普通问答首正文约 0.41 秒、资料问答约 1.67 秒；两用户并发约 11.99/11.78 token/s。这些不是本轮重新跑的性能测试，也不代表持续负载或 p95。原始记录见 [runtime-validation.json](runtime-validation.json)，旧状态见[归档](archive/implementation-status-v0.1.md)。

## 尚未完成的企业部署事项

1. 真实企业资料的 50～100 题标注评估、语义混合检索/重排、精确 token 预算。目前 BM25 每次读取授权片段，小语料试点可用，大库需优化。
2. SSO、网页成员管理、密钥轮换、完整账号生命周期；如需多企业，还须增加独立租户边界。
3. HTTPS 反向代理、可信转发配置、多设备验收、launchd 开机启动、监控告警、长时并发和内存评估。目前仅本机访问、单 Gateway worker。
4. 解析器完整 OS 权限与内存隔离、恶意压缩内容等压力测试；当前独立子进程和超时不等于完整安全沙箱。OCR、复杂版式和结构感知切块尚未实现。
5. 备份轮换、数据保留、离机恢复演练与审计留存。当前本地操作记录不宣称防篡改或满足合规标准。
6. NAS 暂不实施、不阻塞试点；Cloud/DEEP 仍未接入。M6 已有手动搜索闭环，但持续网络可用性、引擎限流、大规模网页质量与正式企业数据留存仍待验收。

引用列表是提供给模型的证据，未自动验证每个论断的语义支持度。权限撤销能阻止继续读取来源，无法回收用户已经看到的答案文字或下载内容。

## 当前启动方式

打开 [本机工作台](http://127.0.0.1:9000/)，使用 `data/owner.key` 中的账号密钥。已有账号和示例无需重新初始化。

```sh
python3 scripts/start_model.py --binary /Users/mac/gemma-lyrics/llama.cpp/build/bin/llama-server
```

其他终端分别运行 `python3 scripts/start_search.py` 和 `uv run python -m local_ai serve`。详细配置、成员管理与备份方法见 [README](../README.md)。
