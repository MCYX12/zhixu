# M6 联网搜索：开工前与完工后核对

## 开工前核对 · 2026-09-13

已通读总计划书 v2.1，用户授权本轮实现 M6，并要求每轮工作前后核对计划。

| 计划条款 | 本轮实施与验收项 |
|---|---|
| §3 SearXNG | 本机独立搜索服务，JSON API，固定源码版本与启动说明 |
| §4 配置 ∩ 用户 ∩ 模式 | 默认配置关闭；当前试点显式启用 owner；仅 WEB 发起搜索；云端和私有资料外发关闭 |
| §4 不外发私有问题/历史 | 使用独立、明确填写的公开搜索词，不自动改写或拼接文档/历史；发送按钮代表本次查询授权 |
| §6 显式模式 | AUTO/LOCAL/KNOWLEDGE 不触发联网；搜索失败不假装已核实 |
| §9 搜索→抓取→清洗→本地总结 | 限制请求数、大小、时间；展示正文/仅摘要、抓取时间与可得发布日期 |
| §9 SSRF | HTTP(S) 白名单、禁止凭证/内网/回环/link-local，DNS 验证并固定连接地址，逐跳验证重定向 |
| §9 网页指令不改变策略 | 网页仅作不可信证据，不提供工具执行，不跟随正文中的指令链接 |
| §8 队列与取消 | 搜索和抓取在现有请求队列内，断连取消，失败释放槽位 |
| §10/11 M6 验收 | 网络适配器模拟回归 + 真搜索/本地模型/网页实测，故障与未验收项如实记录 |

本轮把 M6 提前实施；M4/M5 仍独立待验收，NAS 暂不实施。公开网页抓取需要访问来源站点，其请求不携带用户凭证或历史会话。SearXNG 本机运行也仍会把公开搜索词发给其配置的外部搜索引擎。

| 正文、清洗、来源日期 | 3 个来源、article/main 清洗、正文节选与摘要标记、发布日期未知提示、检索时间和原站；自动与浏览器验证通过 |
| SSRF 与请求预算 | URL/DNS 公网检查、固定 IP 并保留 TLS SNI、逐跳检查、私网/转换地址/混合 DNS/循环/压缩/超量拒绝；测试通过 |

| 排队、错误与取消 | 搜索在生成队列内；HTTP socket 断连取消、并行正文任务取消、故障和空结果释放槽位；测试通过。已发到搜索引擎的查询不能撤回 |
| 引用与历史 | 服务端证据 ID、按账号访问、客户端伪造过滤、联网会话保存/恢复；自动与真实浏览器验证通过 |
| 全部回归 | 81 项测试通过；Ruff/Node/Prettier 检查通过。模拟安全测试与真实模型/网络记录分开 |
| 真实最新信息链路 | 公开搜索官方文档，模型返回检索时的 264 个搜索服务及 [2] 引用；约 11.54 秒，非流式与浏览器流式均通过。详见 m6-runtime-validation.json |

M6 已交付手动联网搜索试点。持续网络可用性、引擎限流、长期网页质量、真实企业问题集及生产数据留存未验收，不能称为生产 SLA。网页解析仅处理静态 HTML/文本，JS 动态页、PDF 来源和登录页可能只提供搜索摘要。
